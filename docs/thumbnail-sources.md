# Thumbnail sources

Read manifest.json before preparing a thumbnail. Files here are cached originals or documented derivatives. The manifest records the primary URL, SHA-256, role and date verified.

Reuse the file when its hash matches. Do not download the same URL again on every revision. If a file is missing or corrupted, fetch only that asset from its recorded primary URL and verify it. Explicit brand refreshes get a new entry; retain the previous source for reproducing old versions.

Company and product identities are different:
- Anthropic company comparison: anthropic/company-mark.svg or company-icon.png. The mark is A plus a diagonal slash.
- Claude model/product: use a separately verified Claude source. The Claude sunburst is not the Anthropic company mark.
- Discord: use symbol-original.svg. symbol-reference.png is a visibility derivative, not a redesigned logo.
- OpenAI: company-mark-reference.png is reused from the earlier reference cache; its exact download URL was not recovered. Do not invent provenance.
- style/chess-approved.png is a composition/material reference. It is not evidence that its old company-logo choice was correct.

Previous references for other brands remain in editing/outputs/thumbnail-rollout-2026-11-03/official-references. Reuse those cached assets after checking their provenance; migrate a needed source into this folder with a manifest entry rather than downloading it again.

Artwork style: physically convincing materials, weighted subjects, dramatic near/far camera perspective and clean topic-driven composition. OpenClaw uses a lobster metaphor here, not a newly invented official logo. Never label generated artwork as an official source asset.


The OpenClaw banner is owner supplied and cached under openclaw/. It inspires a claw-to-contact gesture, not a duplicated set. Discord always stays purple. Shared DA means camera, lighting and material quality; compositions remain specific to each topic.
