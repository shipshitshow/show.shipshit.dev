# Metadata output

- Asset/format, source transcript and recording/publication dates.
- Preserve an approved title; otherwise provide distinct candidates and a recommendation grounded in the asset.
- Final title and description in separate plain-text copy blocks. Apply the channel profile’s narrator and format-specific link policy; include the opener, practical takeaway, chapters from the correct clock when available, and channel footer.
- Comma-separated focused tags (5 to 10, spelling and names, not keyword stuffing); optional `youtube_tags` YAML.
- Keep source-verification notes, unknown claims/timestamps, pending public-page links and test hypotheses outside paste-ready copy.

For a scheduled live, describe the intended question without claiming results, in the fixed order of [the description template](description-template.md). For a recap, package the final edit with a title, thumbnail and description that differ from the livestream's. For a Short, use its complete narrow point, link the full episode and do not fabricate long-form chapters. Report each title's character count.

Recheck https://support.google.com/youtube/answer/9884579 for chapter requirements and https://support.google.com/youtube/answer/146402 for tags. Platform limits can change; approximate editorial length preferences are not official limits.
