# Scorecard shape

One page per host. Delete template instructions from the output. Keep it to roughly
one screen of reading: numbers in the table, judgment in the rows below.

```markdown
# Coach — Host — YYYY-MM-DD "Episode title"

Compared with: YYYY-MM-DD "Previous title". Source: captions, speakers inferred
(confidence: low|medium|high). Fillers are a floor; auto-captions drop some.

**Went well:** one or two specific moments with `m:ss` and a short quote.

| | This stream | Last week |
|---|---|---|
| Time to first real claim (after the countdown) | m:ss | m:ss |
| Turns opening with agreement / with push-back | n / n | n / n |
| uh/um, "like", hedges per 1000 words | a / b / c | a / b / c |
| Longest monologue | s at m:ss | s at m:ss |
| Story turns / read-aloud turns | n / n | n / n |
| Chat mentions | n | n |
| Shrug phrases (whatever, I don't know) | n | n |
| Share of words | % | % |

**First claim:** who said it and when; quote. If none before the first source, say so.
**Agreement vs push-back:** one example of each, or "no push-back moment found".
**Stories vs sources:** the best firsthand story, when it came, and any cold read.
**Chat:** whether a viewer question was taken and where.
**Close:** whether it answered the episode's question; the call to action.

## Keep
1. Action, with the moment that showed it (m:ss).
2. ...
3. ...

## Change
1. Action to try next week, with the moment (m:ss) and what to do instead.
2. ...
3. ...

Check by ear: m:ss, m:ss (moments where the speaker label is uncertain).
```
