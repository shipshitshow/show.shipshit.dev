# Quality gate

Run this before handing over a board. Every line is a yes or no. A no is either fixed or stated plainly in the hand-over.

## Opening

- [ ] The board has a `## Cold Open` with two or three first-sentence options.
- [ ] Each option is a claim plus a stake, readable in under 15 seconds, and stands alone for a replay viewer.
- [ ] No option asks for a like or subscribe, and none starts with a greeting, a stream check or a setup line.
- [ ] Every number or quote in an option is on the board with a source, or marked `CHECK BEFORE SAYING`.

## Title and structure

- [ ] The title's promise is one sentence and the first segment starts delivering it.
- [ ] No more than three segments plus the close. Off-title items sit in the after-show block.
- [ ] A re-hook is planned every 8–10 minutes, and each segment has one chat question.
- [ ] The close names a verdict per host and states what remains unknown.

## Hosts and evidence

- [ ] Each segment has each host's one-line stance, or is marked `Open`. No view is written for a host.
- [ ] Segments marked `Split` get the longest budget. Where both agree, a sceptical-customer question is written down.
- [ ] Each segment opens on a firsthand story with one number per host, or is marked `No firsthand: ask`.
- [ ] Every source is one line that both hosts have read. Nothing is on the board that neither has opened.
- [ ] Opinion, firsthand observation, vendor claim and independently verified evidence are labelled apart.

## Show mechanics

- [ ] Each host can find the next source in a glance; the board has terse talking points of 2–5 bullets under 12 words.
- [ ] A demo has quota, fixture, expected result and recovery path, or the slot is marked unavailable.
- [ ] The on-air checklist is attached to the run sheet.
- [ ] Planned time, actual time and source-video time are kept apart.

## Hand-over note

State what was verified, what was not, which gates are open (first sentence approval, host stances, checks before saying) and what the hosts must do before going live.
