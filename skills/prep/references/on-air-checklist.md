# On-air checklist

One page for the hosts. Attach it to the run sheet you look at while live. Based on the 10 November 2026 audit of the channel's livestreams; the rules cost nothing but attention.

## Before going live

- [ ] Check stream, audio and chat **before** going live. Nothing technical on air.
- [ ] Each of us has written a one-line verdict per segment. Where they differ, that is the segment.
- [ ] We have agreed the first sentence: the promise, under 15 seconds.
- [ ] Every source on the board has been opened by both of us. If neither read it, it is out.
- [ ] Each of us has one story and one number per segment.
- [ ] One chat question per segment is written down, planted if needed.
- [ ] Any live build has a plan for what we say while it runs, or it runs off air.

## On air

| Do | Instead of |
| --- | --- |
| **Start on the claim.** After the countdown the first sentence is the promise, said to the lens. | "And we are live", "how was your week" |
| **Story first, source second.** Open each segment with what happened to us and one number. The source is one line we have read. | Reading timelines off the screen |
| **React with a question.** Ask what it cost, what broke, or whether we would ship it. | "Yeah", "exactly", "mhm" |
| **Say where we differ.** If we disagree, say it and say why. If we agree, one of us asks the sceptic's question. | Nodding along |
| **Look at the lens** for the claim and the verdict. Look at the screen only while showing something. | Eyes on the second screen |
| **Re-hook every 8–10 minutes.** One sentence: what we answered, what is still coming. | Letting the topic drift |
| **Fill or cut the silence.** Say what we expect before a result arrives. | Minutes without speech during a build |
| **Read one chat question per segment** aloud. | Ignoring the chat |
| **Pause instead of shrugging.** One second of silence reads as thinking. | "Whatever", "I don't know", "blah blah blah" |

## Close

- [ ] Answer the title's question using only what we showed.
- [ ] Each of us says in one sentence what we would do on Monday.
- [ ] Say what we still do not know.
- [ ] End the show on the verdicts. Catch-up and housekeeping come after, in an after-show block of five minutes at most, so the replay can end on the verdict.

## After

- [ ] Note the time to the first claim, which segments split, which chat questions we took, and what the build did. These feed the weekly review.
